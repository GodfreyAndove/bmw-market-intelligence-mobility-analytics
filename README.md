BMW SALES BIG-DATASET
======================================
Coverage: 1 Jan 2015 - 31 Jul 2026
Transactions: 1.2 Million Rows
Countries: 24
Models: 11
Channels: 3

STATUS
This is a SIMULATED dataset, not BMW proprietary sales data and not a live BMW feed.
The transaction timestamp, changing prices, FX, and channel behavior are simulated to create a realistic
analytical environment.

PRICE MODEL
Official BMW MSRP anchors were used from BMW Group/BMW USA historical pricing material and current BMW
USA model/pricing pages. Between official anchors, monthly MSRP movement is simulated. Transaction prices
then vary by country market factor, channel, discounts, FX, and market volatility.

POWER BI
Use a dedicated Calendar table for Year/Month/Quarter time intelligence.
Use ISO3 as the geographic key for map visuals.
Use Revenue_USD for global comparisons and Revenue_Local for local-currency reporting.
Treat all sales figures and simulated prices as synthetic.
